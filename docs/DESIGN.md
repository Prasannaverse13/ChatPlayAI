# ChatPlay visual redesign

Reference: the current [Discord homepage](https://discord.com/), inspected in a browser on October 29, 2026, and the user's supplied `DESIGN (13).md`, `tokens (13).json`, `variables (13).css`, and `theme (13).css`.

The attached documents were treated as design reference data. Their embedded agent prompt examples and prescriptive design prose were not treated as independent user instructions.

## Implementation

- `/`: an atmospheric indigo website with a split hero, heavy display typography, centered download/open CTAs, five large feature scenes, a moving word ribbon, an installation guide, FAQs, and grouped footer links.
- `/studio`: the functional application, with the same indigo, lavender, white, and blurple visual language. Existing voting, profiles, settings, export, and game controls remain connected to the server.
- `/studio?view=profiles`, `?view=overlay`, `?view=settings`, `?view=history`: direct feature links.
- `/overlay`: the real, sanitized OBS browser source. Its read-only token and behavior are unchanged.
- `/download/windows`: the local release ZIP generated by `npm run package`. No credentials or session data are included in the archive.

The proprietary Discord fonts are not included. Locally bundled Nunito Sans 900 provides the heavy display treatment, with DM Sans for body text. The original ChatPlay identity and illustrations avoid reusing Discord's logo, mascots, or product screenshots. Invalid extracted reference values such as `#eb459` and range-valued CSS dimensions were not copied into production styles.

## Motion and interaction

The hero artwork floats and responds subtly to pointer movement. Stars twinkle, a robot waves, previews animate chat/intent mapping and game movement, vote bars move, and a continuous word ribbon crosses the page. Feature panels enter through IntersectionObserver, and FAQs animate their expansion.

Navigation dropdowns and the mobile menu work with buttons, keyboard focus, and Escape. The installation guide uses a native modal dialog with focus restoration. The voting preview changes between three modes; the safety preview has a clickable F8 key; the game-profile preview changes its selected game. Preview controls are illustrative and never call game-control APIs.

The footer's Pause animations button stops decorative motion and the chat preview timer. `prefers-reduced-motion` is honored, and feature content stays visible when motion is disabled.

## Generated artwork

Create a polished 3D gaming desk diorama, perspective front three-quarter view, isolated on actual transparent background. A large chunky indigo retro-futuristic computer monitor angled slightly toward the left fills the center. On its screen show a clean dark-purple livestream gaming control interface: a large colorful side-scrolling pixel-art mountain platformer, a thin chat sidebar with colorful avatar circles and simple chat lines, voting bars below the game. Absolutely NO readable text or letters anywhere. A purple wireless game controller lies in front. Two ORIGINAL friendly mascots stand at the base: a small rounded mint-green cuboid robot with a black face display and two glowing oval eyes on the left; a larger lavender round-headed robot with tiny antenna and happy face on the right, wearing orange sneakers. A small upright matching handheld gaming device sits at the right of the monitor. Float two glossy four-point stars and a lavender crystal above the monitor. Fun premium rendered clay, soft subsurface light, realistic bevels, playful gaming cinematic composition, strong electric blue and purple ambient rim light with mint and coral accents. No scenery, no solid background, no floor plane extending beyond objects, no logos, no watermark. Keep all objects fully in frame with ample transparent margin. The monitor should dominate, not the characters. Wide landscape composition 3:2.
